## Priority Recommendations

1. **P0 — Immediate** Remove the typosquatted `com.fastxml.jackson.core:jackson-databind` dependency block from `pom.xml`. This is a confirmed supply-chain attack vector that cannot be remediated by version bumping — it must be deleted.

2. **P0 — Immediate** Upgrade `log4j-core` and `log4j-api` from `2.14.1` to `2.17.1+`. CVE-2021-44228 (Log4Shell, CVSS 10.0) is actively exploited in the wild and enables unauthenticated remote code execution via crafted log messages. The application's `DiscountCalculator` directly imports Log4j, confirming exposure.

3. **P1 — This Sprint** Upgrade `jackson-databind` from `2.9.8` to `2.15.4+` (or latest 2.18.x). Version 2.9.8 carries 53 known vulnerabilities including multiple CVSS 9.8 remote code execution gadget chains via polymorphic deserialization.

4. **P1 — This Sprint** Remove the untrusted HTTP Maven mirror (`http://insecure-mirror.example.net/maven2`) from `pom.xml`. Any artifact fetched over plain HTTP can be silently replaced by a man-in-the-middle attacker.

5. **P2 — Near Term** Replace `mysql:mysql-connector-java:8.0.30` to address CVE-2023-22102 (CVSS 8.3) and resolve the GPL-2.0 license policy violation. Use `com.mysql:mysql-connector-j` (with commercial exception) or `org.mariadb.jdbc:mariadb-java-client`.

6. **P2 — Near Term** Upgrade `commons-io` from `2.4` to `2.14.0+` (fixes CVE-2024-47554 DoS and CVE-2021-29425 path traversal).

7. **P3 — Routine** Upgrade `commons-lang3` from `3.4` to `3.18.0` and `guava` from `24.1.1-jre` to `33.4.8-jre`.
